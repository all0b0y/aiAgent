## Commands
- install: `pnpm i`
- dev: `pnpm dev` (http://localhost:3000)
- test: `pnpm test` · one file: `pnpm test path/to/file.test.ts`
- check (types + lint + tests): `pnpm check` — must be green before you finish

## Layout
- `src/app` — routes and pages (Next.js)
- `src/core` — business logic, no IO; covered by unit tests
- `src/components/ui` — design-system components; build new UI from these
- `src/generated` — generated by `pnpm gen`; edit the source schema instead

## Conventions
- TypeScript strict. Validate external input at the boundary (zod); trust types inside.
- Errors: return `Result<T, E>` from core; throw only in route handlers.
- Styling: only tokens from DESIGN.md via Tailwind theme; no raw hex values in components.
- Names follow GLOSSARY.md; add new domain terms there.

## Definition of done
- `pnpm check` green
- New behaviour has a test that failed before the change
- UI changes verified in the browser at 375 px and 1280 px
- Final message: what changed, how it was verified, what is left

## Ask first
- DB migrations, deleting files, adding dependencies, anything touching `billing/`
